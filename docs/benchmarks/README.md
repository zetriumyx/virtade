# 核心微基准

2026-11-09，共享 Linux x86_64 云容器，Rust 1.99.1，默认 Cargo dev / release 编译选项。100 次服务预热后，10,000 次 JSON null 服务调用和 10,000 次有序单监听事件。代码为 `crates/virt/examples/baseline.rs`，原始结果保存在相邻 JSON。

| 路径 | Debug median / p95 | Release median / p95 |
| --- | --- | --- |
| 服务调用 | 36.16 / 62.42 µs | 18.46 / 27.85 µs |
| 单监听事件 | 34.18 / 59.40 µs | 18.17 / 26.70 µs |

这些数字包含 Tokio 作用域任务调度、超时与权限检查。它们不代表 GUI 内存、WASM 冷启动、原生 Agent 吞吐或专用机器性能。共享容器存在抖动，暂不设置跨平台回归阈值；变更优化前应在固定目标平台重复采样。不要将 debug 与 release 横向当作代码变更收益。
