- Wasmtime：实际 Component 注册服务、事件、面板；fuel、陷阱、内存、权限拒绝；安装/禁用/重载/卸载 generation 撤销、篡改隔离与链接逃逸拒绝。
- 持久 RPC：外部插件通过权限代理复用原生进程监督器，异步请求与原生通知可轮询；禁用撤销连接并回收子进程，旧 generation / 连接不可复用。
- 开放 Provider：外部 WASM 包通过版本化服务贡献 Provider；宿主绑定实际 Provider 身份，合同测试不依赖内置 Provider 名称。
